# Concept behind the Work

I'm a amateur lover of Chinese calligraphy. The logo is a Chinese word 志, meaning *aspiration, ambition*, or *will*. The style is seal script (篆書), a very ancient calligraphy style that has been existing for over 2000 years.

The top part of the logo is designed to mimic the Greek letter $\Psi$, which is usually used to represent the wave function in quantum mechanics, describing the state of a system.
